# CS360
**Briefly summarize the requirements and goals of the app you developed. What user needs was this app designed to address?**
* The goal of my app was to allow users to create an account, log in, and manage a list of events through an easy-to-use interface. It was designed to help users keep track of important dates and events in one place. The app needed to include a working login system, a persistent SQLite database, and CRUD functionality so users could create, read, update, and delete event information. The app included a login screen, a registration option for new users, and an event list screen where users could manage their events. I designed the interface to be simple and intuitive, using clear input fields, buttons, and labels so users could easily understand how to use each feature. Keeping users in mind, I made sure navigation between screens felt seamless and that error messages and confirmations were clear. This approach created a user-centered experience that focused on simplicity and functionality.


**What screens and features were necessary to support user needs and produce a user-centered UI for the app? How did your UI designs keep users in mind? Why were your designs successful?**
* The app required three main screens to meet user needs: a login screen for signing in or registering, an event list screen to display all saved events in a RecyclerView, and an add/edit event section for inputting, updating, or deleting event entries. The UI was designed with clarity and simplicity, arranging input fields, buttons, and lists logically so users could navigate the app intuitively, with error messages and confirmations guiding their actions. These designs were successful because they minimized confusion, streamlined core tasks, and focused on helping users efficiently view and manage their events.


**How did you approach the process of coding your app? What techniques or strategies did you use? How could those techniques or strategies be applied in the future?**
* I approached coding the app by breaking the project into manageable components, starting with user authentication, then setting up the database, and finally connecting the UI to the backend. I used modular coding practices, separating responsibilities into classes like DatabaseHelper, EventAdapter, and individual activity files, and maintained consistent naming conventions with clear in-line comments to keep the code organized and readable. I also tested features incrementally using the Android Emulator to catch errors early and ensure functionality at each stage. These techniques can be applied in future projects to maintain clean, maintainable code, support easier debugging, and allow for scalable, well-structured app development.


**How did you test to ensure your code was functional? Why is this process important, and what did it reveal?**
* I tested the app by running it in the Android Emulator and verifying each feature step by step. This included checking user registration and login, confirming that events could be added, edited, and deleted correctly, and ensuring that the database maintained data after the app was closed and reopened. I also tested navigation between screens to make sure the UI responded as expected. This process was important because it allowed me to catch logic errors and layout issues early, ensuring that the app functioned smoothly. It revealed small bugs in data handling and activity transitions that could be fixed before finalizing the app.


**Consider the full app design and development process from initial planning to finalization. Where did you have to innovate to overcome a challenge?**
* During the full app development process, one challenge I faced was ensuring that changes in the database, such as adding or deleting events, were immediately reflected in the UI. To overcome this, I had to implement real-time updates by refreshing the RecyclerView adapter whenever the database changed. I also had to carefully manage data flow between activities using intents to maintain consistency across screens. This required creative problem-solving to synchronize the backend and frontend efficiently, ensuring a smooth and responsive user experience.


**In what specific component of your mobile app were you particularly successful in demonstrating your knowledge, skills, and experience?**
* I was particularly successful in the **DatabaseHelper** component, which manages all interactions with the SQLite database. This class demonstrates my ability to implement full CRUD functionality, handle database connections efficiently, and integrate backend operations with the UI. By ensuring that event data could be added, updated, deleted, and retrieved reliably, I showcased my understanding of database management, activity communication, and real-time UI updates within an Android application.
